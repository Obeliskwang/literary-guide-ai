# literary-ai-guide

#### Description
本项目基于Python、LangChain、LLM与Chroma向量数据库搭建RAG智能问答系统，可实现经典文学名著文本预处理、向量知识库构建、名著阅读导赏、人物关系查询与多轮对话交互。
